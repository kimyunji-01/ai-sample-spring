# _core

## 목적
도메인에 종속되지 않는 프로젝트 전반의 공통 유틸리티, 설정, 예외 처리.

## 주요 파일
| 파일명 | 설명 |
|--------|------|
| utils/Resp.java | 공통 응답 래퍼 (성공/실패) |

## 하위 디렉토리
- `utils/` - 공통 응답 래퍼 및 유틸리티 클래스

## AI 작업 지침
- 모든 REST API 응답은 `Resp.ok()` 또는 `Resp.fail()`을 통해 반환되어야 함.
- 전역적인 예외 처리가 필요한 경우 이 폴더 아래에 `ExceptionAdvice` 등을 위치시킴.
