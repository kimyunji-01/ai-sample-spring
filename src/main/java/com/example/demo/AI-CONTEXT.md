# demo

## 목적
이 프로젝트의 주요 비즈니스 로직과 도메인 레이어가 위치한 베이스 패키지.

## 주요 파일
| 파일명 | 설명 |
|--------|------|
| DemoApplication.java | Spring Boot 구동 클래스 |

## 하위 디렉토리
- `board/` - 게시글 관련 로직
- `reply/` - 댓글 관련 로직
- `user/` - 사용자 정보 및 인증/인가 관련 로직
- `_core/` - 전역 예외 처리 및 공통 유틸리티

## AI 작업 지침
- 모든 도메인 관련 파일은 각 폴더 내에 플랫하게 위치함.
- `_core`는 도메인과 무관한 전역 로직을 다루므로, 함부로 수정하기보다 재사용 가능성을 고려할 것.
